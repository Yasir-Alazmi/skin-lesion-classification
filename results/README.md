# Experiment Results

Outputs of the lesion-grouped evaluation on HAM10000 (test set: 1,503 images, 1,118 lesions, used once).
Everything except `splits.csv`, the prediction CSVs and the history JSONs is regenerated by
`python scripts/report.py`.

## Metrics

| File | Description |
|------|-------------|
| [`metrics.md`](metrics.md) | Overall and per-class metrics with 95% lesion-level bootstrap CIs |
| [`metrics.json`](metrics.json) | Same numbers, machine-readable (includes confusion matrices) |

## Inputs (committed)

| File | Description |
|------|-------------|
| [`splits.csv`](splits.csv) | `image_id, lesion_id, dx, split`: the lesion-grouped 70/15/15 assignment |
| `vit_test_predictions.csv`, `efficientnet_test_predictions.csv` | Test predictions: `image_id, label, pred, p_<class>` (1,503 rows each) |
| `history_vit_b16.json`, `history_efficientnet_b3.json` | Per-epoch training curves |

## Figures

| File | Description |
|------|-------------|
| `model_comparison.png` | Accuracy, macro-F1, macro-AUC, mean sensitivity/specificity for both models |
| `training_history.png` | Loss, accuracy and validation AUC per epoch |
| `confusion_matrix_{vit_b16,efficientnet_b3}.png` | Normalised confusion matrices (counts in grey) |
| `roc_curves_{vit_b16,efficientnet_b3}.png` | One-vs-rest ROC curves per class |
| `sensitivity_specificity_{vit_b16,efficientnet_b3}.png` | Per-class sensitivity and specificity |
| `class_distribution.png`, `hair_removal_demo.png`, `__results___files/` | Dataset class balance and preprocessing illustrations (no model results) |

## Headline numbers (test set)

| Model | Accuracy | Macro-F1 | Macro-AUC |
|-------|----------|----------|-----------|
| ViT-B/16 | 0.806 | 0.710 | 0.955 |
| EfficientNet-B3 | 0.741 | 0.612 | 0.934 |

Intervals and per-class results are in [`metrics.md`](metrics.md). Model weights are not committed
(see [`../models/README.md`](../models/README.md)).
