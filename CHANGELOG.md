## [Unreleased]

### Added (2.1.0 candidate, not yet committed)
- ConvNeXt-S ensemble (`src/ensemble.py`, `models/ensemble/ensemble_config.json`): 384/448 px, flip TTA, log-prob average, per-class bias tuned on validation. Test (second look, fixed configuration): accuracy 0.837, macro-F1 0.786, balanced accuracy 0.819, melanoma sensitivity 0.720, versus ViT-B/16 0.806 / 0.710 / 0.712 / 0.673.
- `kaggle/r1`, `kaggle/r2`: Kaggle training scripts; `scripts/final_eval_r2.py` (single-use final evaluation); `tests/test_ensemble.py`.
- `app.py` and `demo.py` run the 4-member ensemble (the 5th reported member's weights were not kept).

### Findings
- Resolution 384/448 and a ConvNeXt backbone helped most; a metadata branch (age, sex, site) did not help; seed variance is large.

### Caveats
- The test set has now been used twice (baselines, then the fixed ensemble). Reported ensemble numbers refer to the 5-member ensemble, the demo runs 4 members.

### Planned
- Grad-CAM visualisation for model interpretability
- ONNX export support
- Streamlit inference demo

## [2.0.0] — 2026-11-09

### Changed (all reported numbers)
- Evaluation now uses a lesion-grouped 70/15/15 split (`src/split.py`, `results/splits.csv`); model selection on validation macro-F1; test set used once.
- **Replaced the v1.0.0 results.** The 94.2% accuracy claim came from a notebook that could not be reproduced. Verified results: ViT-B/16 accuracy 0.806, macro-F1 0.710, macro-AUC 0.955 (melanoma sensitivity 0.673); EfficientNet-B3 accuracy 0.741, macro-F1 0.612, macro-AUC 0.934.
- Prediction CSVs in `results/` regenerated from the new runs; figures regenerated by `scripts/report.py`.
- `app.py` is now a Gradio app that runs the trained ViT-B/16 (top-3 probabilities, research-only disclaimer); `demo.py` is a thin CLI over the same code (`src/inference.py`).

### Added
- `scripts/report.py`: metrics with 95% lesion-level bootstrap CIs (`results/metrics.json`, `results/metrics.md`).
- `scripts/train_all.ps1`, `scripts/train_status.ps1`, `scripts/export_weights.py`; GPU data pipeline and image cache.
- CPU tests for inference and the report helpers (no checkpoint needed).

### Removed
- `index.html` (a JavaScript page that simulated predictions) and `compute_calibrated_probabilities` (heuristic stand-in probabilities used when no weights were present).
- Stale figures and Kaggle-notebook outputs that showed the old numbers.

## [1.0.0] — 2026-04-26

### Added
- Full training pipeline for EfficientNet-B3 and ViT-B/16 on HAM10000
- Hair removal preprocessing using Black-Hat morphology + TELEA inpainting (`src/preprocess.py`)
- Focal Loss with class-frequency weighting (`src/loss.py`)
- WeightedRandomSampler for class imbalance mitigation (`src/dataset.py`)
- 2-phase fine-tuning: frozen backbone → full unfreeze at epoch 5 (`src/train.py`)
- EarlyStopping on validation AUC with patience=7 (`src/train.py`)
- Per-class evaluation: Accuracy, Precision, Recall, F1, AUC (`src/evaluate.py`)
- Visualisation suite: ROC curves, confusion matrices, training history, model comparison (`src/visualize.py`)
- Stratified 70/15/15 train/val/test split (`src/dataset.py`)
- Experiment results, plots, and prediction CSVs (`results/`)
- Comprehensive README with architecture diagram, dataset details, and usage examples
- MIT License
- `.gitignore` for Python, PyTorch, and Jupyter environments

### Note
- The results originally published with this release were not reproducible and are retracted; see 2.0.0.
